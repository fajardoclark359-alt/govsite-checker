OSINT Intelligence Tools

Open Source Intelligence tools for cybersecurity research, threat analysis, and reconnaissance.

🌍

IP Geolocation

Geolocate an IP address to find country, city, ISP, ASN, and coordinates.

🔍

Reverse IP Lookup

Find other domains hosted on the same IP address. Useful for shared hosting reconnaissance.

🔗

DNS Enumeration

Full DNS record enumeration including A, AAAA, MX, NS, TXT, SOA, CNAME, and SRV records with reverse DNS.

📄

WHOIS / RDAP Lookup

Retrieve domain registration data including registrar, dates, status, and name servers.

🔒

SSL/TLS Certificate Analyzer

Analyze SSL certificates: issuer, expiry, subject alternatives, cipher strength, and protocol version.

📜

Port Scanner

Scan common ports to identify open services: HTTP, SSH, FTP, databases, and more.

🧰

Technology Detection

Detect web technologies: server, CMS, frameworks, analytics, CDN, and programming languages.

🌐

Subdomain Discovery

Discover subdomains by checking DNS for common names. Find hidden services and infrastructure.

🛡

Security Headers Analysis

Comprehensive HTTP security headers audit with grading. Checks HSTS, CSP, CORS, cookies, and more.

🔎

Google Dorking Helper

Generate Google dork queries to find exposed files, login pages, config leaks, and more.

💣

URLhaus Malware Check

Check URLs against the URLhaus malware database. Identify malicious URLs and phishing sites.

📧

Email Header Analysis

Paste raw email headers to trace the originating IP address, check SPF/DKIM, and geolocate the sender.

⚠

Domain Reputation & Threat Intelligence

Check if a domain is associated with malware, phishing, typosquatting, or other threats. Includes brand impersonation detection.

Have I Been Pwned — Breach Classification

Enter an optional HIBP API v3 key to query real breach data per domain. Without a key, the app still classifies each site using automated exposure probes (sensitive files) and security-header checks.
